## [AI 早报：Codex 百万上下文、DeepSeek 调价、Stripe 收购 OpenRouter](https://daily.juya.uk/issues/2026-08-17/) ⭐️ 7.0/10

2026 年 8 月 17 日的 AI 早报显示：Codex 负责人 Tibo 发布了开启 100 万 token 上下文窗口的教程，并确认 Codex 未来将接入 Astra；DeepSeek API 正式上调价格并启用峰谷定价；据报道 Stripe 已敲定以逾 70 亿美元收购 OpenRouter。 这些动态表明 AI 基础设施市场正在整合、模型厂商之间的竞争加剧：100 万 token 上下文让 Codex 在处理大型代码库时更实用，DeepSeek 调价改变开发者的成本结构，而 Stripe 收购 OpenRouter 可能重塑 AI 模型 API 的接入与计费方式。 早报还提到：开启 Codex 的 100 万上下文需在 config.toml 中设置约 100 万 token 的上下文窗口；DeepSeek 调价后 OpenCode 同步调整了 Go 额度；SuperGrok Heavy 订阅用户在存续期内可免费使用 Cursor Ultra；Dario Amodei 回应了 AI 风险沟通与监管批评；OpenAI 被曝解散 Preparedness 团队。

rss · Juya AI Daily · 8月17日 01:45

**背景**: Codex 是 OpenAI 推出的 AI 编程代理，可帮助工程师处理代码库；上下文窗口越大，它一次能处理的文件和指令就越多。DeepSeek 是一家以低成本、开放权重大语言模型闻名的中国 AI 公司，其 API 被大量开发者使用。OpenRouter 是一个提供统一 API 接入多家大模型厂商的平台，负责模型路由与计费，目前已宣称有 420 万用户和 25 万多个应用在使用。
