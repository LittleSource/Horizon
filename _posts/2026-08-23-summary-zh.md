## [AI 早报：DeepSeek 周末计价、Codex CLI 提速 25 倍](https://daily.juya.uk/issues/2026-08-23/) ⭐️ 6.0/10

2026-08-23 的 AI 早报报道了 DeepSeek 宣布周末全天统一按低谷价收费、uv 作者重做 Codex CLI 启动提速约 25 倍，以及多项开发者工具更新。早报还涵盖 Firecrawl 上线 Developer Index、Codex 缓存命中率调查、Cursor 文档变动和 Anthropic 关于 Claude Code 配置的澄清。 对于 AI 从业者而言，DeepSeek 周末低谷价可显著降低批量或实验性任务的 API 成本，而 Codex CLI 启动提速能改善日常终端编码代理的工作流。该早报还涉及缓存命中率下滑和性能降智疑虑等信任与透明度问题，这些都会影响开发者对 AI 工具的评价。 DeepSeek 的新计费自 2026 年 8 月 23 日起生效，周末全天按低谷价计算。此外，uv 作者（Astral）据称重做了 Codex CLI 启动，提速约 25 倍，但摘要未给出具体基准数字。其他内容包括：部分 Codex 用户缓存命中率下降正在调查中；Cursor 文档不再将 SuperGrok Heavy 作为 Cursor Ultra 的附赠权益；Anthropic 否认其测试 Claude Code 配置会降低性能。

rss · Juya AI Daily · 8月23日 01:30

**背景**: DeepSeek 是一家中国 AI 公司，其 API 采用峰谷计费模式，低谷时段价格更低；将低谷价扩展到周末是一项显著的定价调整。Codex CLI 是 OpenAI 的终端 AI 编码代理，可在本地运行；uv 是 Astral 开发的、基于 Rust 的极快速 Python 包与项目管理器。Firecrawl 是一个专为 AI 应用设计的网页爬取、抓取和搜索 API，可将网页内容转换为干净的 Markdown 或结构化数据。

## [AI 早报：DeepSeek 多模态、Codex 2000 万用户、OpenAI 降价](https://daily.juya.uk/issues/2026-08-22/) ⭐️ 6.0/10

2026 年 8 月 22 日的 AI 早报报道：DeepSeek 发布了实验性多模态模型 DeepSeek V4 Flash Vision Exp；OpenAI Codex 负责人 Tibo 确认活跃用户达 2000 万，并解释 sub2api 相关的额度问题；OpenAI 还将 GPT-5.6 Sol 的 API 价格下调超过 20%。 这很重要，因为 DeepSeek 正扩展多模态能力，而 OpenAI 同时下调 API 价格并提升透明度，加剧了 AI 实验室之间的竞争。开发者可获得更便宜的 GPT-5.6 访问、更清晰的用量追踪，以及 DeepSeek 面向智能体的新视觉模型。 DeepSeek V4 Flash Vision Exp 是 DeepSeek V4 Flash 0731 的实验性视觉版本，可在同一请求中接受文本和图像；DeepSeek Harness 更新至 v0.1.1 rc.1 并支持官方多模态。Tibo 表示 Codex 和 ChatGPT Work 用户将获得 banked reset，而 sub2api 订阅转 API 共享不被支持；其他内容包括 OpenAI 按 API 密钥追踪用量功能，以及 Claude Security 扫描接入 Claude Mythos 5。

rss · Juya AI Daily · 8月22日 01:59

**背景**: 本条新闻是一份每日 AI 简报，将多个动态汇总在一篇短文中。DeepSeek Harness（dsh）是 DeepSeek 基于 Cordis 框架开发的开源智能体 harness，所有能力均可作为插件替换。OpenAI Codex 是编程智能体；banked reset 指额度重置机制，sub2api 指将付费 ChatGPT 订阅转成 API 的第三方工具，OpenAI 不支持这种做法。
