## [宇树科技 IPO 定价 150.8 元，DeepSeek API 涨价，GPT-5.6 Luna 免费](https://blog.csdn.net/weixin_39786569/article/details/163565119) ⭐️ 6.0/10

宇树科技将 IPO 发行价定为每股 150.8 元，可能催生一批 90 后千万富翁。该汇总还报道了 DeepSeek 将大幅上调 API 价格，以及 GPT-5.6 Luna 可无限免费使用的消息。 这些动态影响投资者、开发者和 AI 用户。IPO 发行表明中国机器人初创企业日益走向商业化成熟，API 调价将影响依赖 DeepSeek 低成本模型的开发者，而 GPT-5.6 Luna 的免费使用可能改变用户的采纳习惯。 宇树科技是王兴兴 2016 年创立的杭州机器人公司，以四足机器人和人形机器人闻名。DeepSeek 是一家以开源权重、低成本大语言模型著称的 AI 公司；文章称其 API 价格将大幅上涨，但未给出具体的新费率。

rss · CSDN 极客头条 · 8月7日 06:50

**背景**: 宇树科技（法定名称为杭州宇树科技）开发四足机器人和人形机器人，用于工业和消费场景。DeepSeek 由梁文锋于 2023 年创立，凭借 DeepSeek-R1 等低成本、高性能大语言模型引起轰动。IPO 每股 150.8 元的发行价之所以引人注目，是因为它可能让许多 90 后员工成为千万富翁。汇总中还提到 GPT-5.6 Luna 提供无限免费使用，但摘要未展开细节。

## [AI 早报：Astra、CosyVoice Studio 与 Seedance 2.5 等动态](https://daily.juya.uk/issues/2026-08-08/) ⭐️ 6.0/10

2026 年 8 月 8 日的 AI 早报提到，OpenAI 称即将推出的 Astra 模型展现重大智能体/网络能力，但将推迟发布；同时，阿里巴巴发布 CosyVoice Studio，火山引擎上线 Seedance 2.5，Claude Code 也更新了默认模式。 这轮更新显示 AI 生态正加速向智能体助手、语音生产力工具和多模态视频生成方向发展。开发者和企业需要跟踪这些发布，以便选择合适的平台和模型。 Astra 是 OpenAI 尚未发布的下一款主要模型，其内部版本已解决十项数学难题，按 Sol API 费率计算每个问题的 token 成本约 2000 美元。CosyVoice Studio 被称为中国首个一站式 AI 语音生产力平台，而 Seedance 2.5 则是支持原生 30 秒一次生成的音视频联合生成模型。

rss · Juya AI Daily · 8月8日 00:43

**背景**: 这是一份来自 daily.juya.uk 的每日 AI 新闻摘要，汇总模型发布和产品更新。OpenAI 将 Astra 定位为下一代模型，允许多个智能体协同处理长达数小时或数天的复杂任务。CosyVoice 是阿里云的文字转语音与声音克隆服务，Seedance 则是字节跳动的视频生成模型系列。
