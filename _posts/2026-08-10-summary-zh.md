## [科技早报：酒店评级陷阱、AI 广告、Edge 扩展变动](https://sspai.com/post/113268) ⭐️ 5.0/10

这期科技早报涵盖多条新闻：央视曝光酒店评级标识消费陷阱，《时代》网站测试仅 AI 可见的广告，微软 Edge 浏览器将禁用 Manifest V2 扩展，美国调查中国 AI 企业使用海外英伟达芯片。 这些新闻涉及消费者权益保护、浏览器生态变化以及中美 AI 技术竞争。Edge 扩展变更会影响普通浏览器用户，而英伟达芯片调查可能改变中国 AI 企业获取先进硬件的途径。 其他内容包括：油价上涨推动美国混动车需求激增，以及廉价手机壳存在毒性隐患。《时代》网站展示的广告仅供 AI 系统识别，普通读者无法看到。

rss · 少数派 · 8月9日 23:08

**背景**: Manifest V2 是 2012 年推出的浏览器扩展规范，目前正被 Manifest V3 取代。Chrome 从 2024 年起开始禁用 Manifest V2 扩展，计划到 2026 年 7 月 8 日让所有用户默认禁用。基于 Chromium 的 Microsoft Edge 也遵循同样的弃用路径。这一变化影响深远，因为许多流行的广告拦截和隐私扩展依赖 Manifest V2 中 V3 所限制的功能。

## [AI 早报：GLM 5.2 降价、Hassabis 转任、Claude 安全进展](https://daily.juya.uk/issues/2026-08-10/) ⭐️ 5.0/10

2026 年 8 月 10 日的 AI 早报称，OpenRouter 上部分供应商将 GLM 5.2 的 API 价格降至 0.5 折（原价的 5%），具体原因和持续时间未公布。报道还提到 Hassabis 考虑离职后被挽留、转任 DeepMind 董事长，远景乌兰察布星河基地投产（规划容量 2GW），以及 Claude Code 主创称多层防御已基本解决提示词注入威胁。 这些动态表明 LLM API 市场竞争加剧、全球顶尖 AI 实验室之一 DeepMind 迎来领导层交接，以及 AI 数据中心仍在持续大规模投入。如果 Claude 的安全说法属实，将有助于缓解人们对需要浏览和处理不可信内容的智能编码工具的担忧。 GLM-5.2 是采用 MIT 开源许可的模型，支持 100 万 token 上下文，在 Terminal-Bench 2.1 上得分为 81.0，接近 Claude Opus 4.8 的 85.0。Hassabis 转任的消息在简报中属“据报道”而非官方确认，折扣的原因和持续时间也未说明。

rss · Juya AI Daily · 8月10日 01:33

**背景**: OpenRouter 是一个统一的 API 平台，让开发者通过一个接口访问多家 LLM 供应商，并常常提供有竞争力的价格。GLM-5.2 是智谱 AI 面向编程和长周期智能体任务的开源旗舰模型。提示词注入是一种安全攻击方式，利用精心构造的输入（例如网页中的文本）诱使 LLM 做出非预期行为；维基百科指出，技术护栏有助于区分任务指令与检索到的数据。
